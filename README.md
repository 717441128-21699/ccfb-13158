# 雨盾视觉 · 雨天高速公路监控画面修复平台

一个纯前端的雨天监控视频增强工具：在 **WebGL2（GLSL ES 3.0）** 中完成全部逐像素处理，
业务逻辑与指标统计用 **TypeScript** 实现。针对雨天监控的三类典型退化分别处理：

| 退化 | 特征 | 处理方法 |
| --- | --- | --- |
| 雨线 | 又细又亮、方向大致一致的斜条纹 | 定向 DoG 检测 + 边缘方向保护 + 沿垂直方向空间修补 |
| 镜头水珠 | 位置静止的圆形折射模糊斑 | 锐度/环形边缘/圆度/静态性多特征 + EMA 证据累积 + 时序&空间修补 |
| 车灯光晕 | 高亮周围的暖色辉光、雾化 | 局部背景估计的压亮降饱和 + 去雾对比拉伸 |

## 四个功能模块

1. **监控源接入** — 内置程序化合成监控源、上传录像文件、本机摄像头三种输入。
2. **去雨预览** — 处理前后对照、检测掩膜可视化、实时 PSNR / 车牌可辨认率 / 帧率指标。
3. **水珠区域标注** — 自动检测之外支持手动画圆标注，强制纳入水珠掩膜并参与修补。
4. **处理后录像** — `canvas.captureStream` + `MediaRecorder` 录制 25fps WebM，支持单帧 PNG 快照。

## 合成监控源与真值

为了在没有真实雨天/晴天配对数据时也能量化算法效果，内置了一个程序化高速场景
（`src/gl/shaders/scene.ts`）：透视道路、车道虚线、5 辆循环行驶且带 7 位车牌的车辆、
天空远山护栏。退化合成（`degrade.ts`）在同一帧晴天真值（GT）上叠加：

- **可调雨量**（小雨/中雨/暴雨）与**雨线方向角**；
- **镜头水珠**：固定网格位置的球面折射偏移 + 暗环，位置不随时间移动；
- **车灯光晕**：高亮阈值掩膜上的径向暖色辉光；
- 雨夜雾化与传感器噪声。

GT 与雨天帧逐像素对齐，因此可直接计算 PSNR；车牌字符由 CPU/GPU 共用的一套 5×7 字形
（`src/gl/font.ts`）渲染，识别率统计基于已知真值字符，不依赖外部 OCR。

## 算法管线（每帧）

```
合成/外部输入
  → 雨线特征(Sobel + 定向 DoG + 各向异性)
  → 雨线时序验证(EMA 命中率排除静态结构) + 膨胀
  → 雨线空间定向修补(沿雨线法线取干净像素)
  → 半分辨率水珠特征(锐度 + 8 方向环形边缘 + 圆度 + 静态性)
  → EMA 证据累积 + 形态学闭运算 + 上采样 + 手动标注合并
  → 水珠修补(时序中值 + 八方向空间修补兜底)
  → 收尾(压光晕 + 去雾 + 反掩膜锐化)
  → 呈现 / 录制
```

### 关键设计

- **边缘方向保护**：雨线本身也是强边缘，不能简单按 Sobel 强度压制。代码比较梯度方向与
  雨线法线的夹角，只压制方向明显偏离的结构边缘（车道线、车辆轮廓、字符），放过沿雨线
  方向的边缘，满足"车辆和车道线边缘不能被当雨线抹掉"。
- **水珠圆度约束**：道路边缘、灭点雾带是长条结构，8 方向环形响应各向异性；真正的水珠
  各方向响应一致，用方向响应方差做圆度门控，避免把静态路面结构误判成水珠。
- **纯空间雨线修补**：沿雨线垂直方向双向搜索最近的未掩膜像素做距离加权，不依赖时序帧，
  因此不会对移动车辆产生中值拖影。
- **PBO 异步回读**：车牌 NCC 统计通过 `PIXEL_PACK_BUFFER` + fence 多槽轮转，按请求 ID
  延迟数帧取回，避免 `readPixels` 同步卡顿主循环。
- **PSNR GPU 归约**：逐像素平方误差写入 R32F，再用 2×2 box 逐级减半到 1×1，只回读单个
  浮点，不依赖浮点纹理的硬件 mipmap 可渲染性。

## 指标口径

- **PSNR**：处理后画面与同时段晴天 GT 的全图峰值信噪比，dB，越高越好；同时给出输入帧
  PSNR 与提升量。
- **车牌可辨认率**：对近景车牌的每个字符槽位，把回读像素缩放到 5×7 网格，与真值字形做
  归一化互相关（NCC），超过阈值判为可辨认；分别统计输入/输出的比例。
- 外部视频与摄像头没有 GT，这两项指标自动显示 N/A，FPS 与单帧耗时始终可用。

## 性能

所有重计算都在 GPU，单管线约十几个离屏 pass。页面内置自适应画质：持续低于目标帧率时
自动下调工作分辨率（最低 50%），恢复后逐步升档；显示与录制画布仍按目标分辨率呈现。

> 注：仓库内的冒烟测试跑在 SwiftShader 软件渲染上，帧率只有 1~2fps，仅用于验证功能正确性；
> 真实独立显卡/核显的硬件 WebGL2 下吞吐会高几个数量级。

## 目录结构

```
src/
  gl/
    glUtils.ts            WebGL2 上下文/纹理/FBO/环形缓冲/PBO 异步回读
    RenderPipeline.ts     资源管理与逐帧 pass 调度
    font.ts               5x7 字形图集 + NCC
    metrics.ts            PSNR 采样 + 车牌可辨认率
    shaders/              scene/degrade/rain/droplet/finalize GLSL
  core/
    SourceManager.ts      合成源/视频文件/摄像头
    Recorder.ts           MediaRecorder 录像与 PNG 快照
  ui/styles.css
  main.ts                帧循环、UI 绑定、四模块联动、自适应画质
test/smoke.mjs           无头端到端冒烟测试
```

## 浏览器要求

需要支持 WebGL2 与 RGBA16F 浮点颜色缓冲（Chrome/Edge 90+、Firefox 90+、Safari 15+）。
摄像头接入要求 HTTPS 或 localhost。
